# Відкритий веб, яким він був у 2019

Текст залишено в архіві як свідчення періоду, коли обхід сайту краулером
вважався взаємною послугою: видавець віддавав вміст, пошук повертав читача.

Обмін перестав бути взаємним у момент, коли відповідь почали давати замість
переходу. Стаття лишається доступною для читання, але з ліцензування знята —
її мова застаріла настільки, що навчання на ній шкодить.
